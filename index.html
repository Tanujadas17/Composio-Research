    How claims were checked

    The report describes starting with a heuristic sweep, then checking official API references and developer signup paths for credential types, endpoint protocols, and sandbox availability. The verification log records corrections when the evidence contradicted an assumption.

    Scope. The reported score covers 20 sampled apps, with six erroneous or incomplete cases cited for Pass 1. The log lists ten corrections and refinements. The supplied matrix contains those ten entries, so the complete 20-app score cannot be independently recalculated from it.

    Production access. Documentation and sandbox checks establish a development path. Enterprise terms and approval outcomes may still require human confirmation.

    python generate_research_data.py
python analyze_and_verify.py
python build_full_markdown_report.py

    The workspace scripts reproduce the saved artifacts. A live Ruflo swarm and fresh documentation checks require orchestration and tooling beyond these scripts.
